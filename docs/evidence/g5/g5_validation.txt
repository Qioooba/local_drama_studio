Queue / recovery invariants
---------------------------
- Job create requires Idempotency-Key; same payload replays one persisted Job, different payload fails with stable mismatch error.
- Dependencies block claim until upstream Job is SUCCEEDED; claim is transactional and priority/creation ordered.
- A worker cannot hold more than one active attempt; each Attempt has an unguessable lease token, 60-second default lease and heartbeat extension.
- Worker lease expiry marks Attempt ORPHANED and requeues only when side effects are not known; provider-job uncertainty goes to NEEDS_ATTENTION.
- retry creates a new Attempt path without changing input snapshot; clone creates a new Job with explicit clone lineage; cancel is separate from retry.
- Outbox events are persisted with queue state changes and exposed by cursor-based SSE; frontend follows the loopback stream and refreshes real job state.
- Artifact registration rejects absolute/escape/partial/symlink paths, hashes completed local files and is idempotent for the same Attempt/kind/path.
- Matrix plan estimate/confirm uses lazy expansion and per-cell Jobs; per-cell cancel is independent.
