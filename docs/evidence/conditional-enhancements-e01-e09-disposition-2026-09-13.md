# E01—E09 条件性增强裁决（2026-09-13）

本文第 6 节明确规定 Phase 0—6 完成后不要求自动开发 E01—E09；只有真实瓶颈满足启动条件时才可启动。本轮逐项裁决如下。

| 项 | 裁决 | 证据与原因 |
|---|---|---|
| E01 低成本分镜预演 | `ALREADY_COVERED / NOT_TRIGGERED` | 已有 `DirectorTimelinePreview`、联系表与序列预览；本轮没有出现“现有预览无法提前发现顺序/时长问题”的重复样本。 |
| E02 少量创作增强 | `NOT_TRIGGERED` | K09—K13 的范围、请求身份、质量门禁已通过；两集样本的人物、上下集证据承接和源范围可解释，没有出现可重复的别名合并或结局改写失败。 |
| E03 对象级自然语言细改 | `NOT_TRIGGERED` | 结构化镜头编辑与四种操作已经可用；没有用户频繁重复同类自然语言细改的量化证据。按文档不得为此新建 Agent/MCP 平台。 |
| E04 H3 条件编码缓存 | `NOT_TRIGGERED` | 真实 H3 小样已完成，但没有分阶段事实证明条件编码是主要且可避免的热路径成本；已有 Comfy 缓存是否覆盖收益尚无反例。不得凭单次墙钟开发张量缓存。 |
| E05 H3 新模式/参考/Motion Context/二采 | `NOT_TRIGGERED` | 当前发布的 H3 图片到视频路线已生成真实带音轨 MP4；没有明确镜头需求被当前路线阻塞。错误的 UI 截图输入属于验收输入选择错误，不是新增模型模式的理由。 |
| E06 超长镜头内部执行分段 | `NOT_TRIGGERED` | 两集样本镜头均可在现有创作拆镜和计划范围表达；没有一个必须超过当前 Profile 单次能力且不可拆解的真实镜头。 |

| E08 语义质检/音频优先/裁头 | `NOT_TRIGGERED` | 技术 QC、人工批准分离；没有重复人物/动作误判或对白密集时长返工样本。第一轮不合格画面由错误输入造成且人工正确拦截，不足以授权新增 VLM/TTS 链。 |
| E09 最小诊断包与阶段耗时 | `ALREADY_COVERED` | Job/attempt、input snapshot、Profile/Workflow、媒体 SHA、错误码、真实总墙钟与 UAT traceback 已足以复现本轮故障；无法取得的编码/采样/解码细分仍保持未知，未伪造 ETA。 |

结论：E01—E09 均已按其启动合同完成裁决；本轮没有被真实证据触发但尚未实现的增强项。根据第 6 节停止线，不继续扩大产品范围。
