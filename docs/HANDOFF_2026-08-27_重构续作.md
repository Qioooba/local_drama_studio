## 2. 硬性红线（违反=返工）

1. **无补丁/无双写**：纵向切片纪律（新 owner 最小可用 → 等价验证 → 切换 → 当期删旧入口）。
2. **镜头工作媒体唯一真值 = `shot_working_media_slots`**；`selections` 表仍被 reviews/g6/timeline/contact_sheets/migration_0061 使用——只有其"镜头工作媒体"语义退役，其余用途不得动。
3. Visual Lab 采纳走 `visual_lab_promotions`（SHOT lineage），不写 selections、不自动 selected/approved。
4. 隐藏≠删除：G 门禁/lease/comfy 直控端点保持可用，只是不出现在公开 OpenAPI 与普通 UI。
5. 普通创作模式不暴露 G 码、provider internals、lease、raw JSON、UUID。
6. 改路由/schema 后必须 `app.openapi()` 重生成 `docs/openapi/openapi.json`（快照契约测试会比对）。
7. 改动使行号结构变化后必须跑 `python scripts/audit_architecture_debt.py` 重生成清单（守卫按 id 比对，禁止新增条目）。
