## 5. 必须保持的架构决策（切勿用补丁/双写破坏）

- **单一真值**：镜头工作媒体真值 = `shot_working_media_slots`（不是 `selections`）。`selections` 仍被 `reviews.py`（FORMAL_SELECTION / PROXY_WINNER）、`g6_readiness`、`timeline.py`、`contact_sheets`、`migration_0061` 等使用——**只迁移“镜头工作媒体”真值，不要删 `selections` 的其余用途**。
- **Visual Lab 采纳**= 记录 `visual_lab_promotions`（SHOT lineage）+ 在 Shot Studio 浮现为候选；不写 `selections`、不自动 selected/approved。
- **G 门禁 / worker lease** = 从公开 OpenAPI 隐藏（`include_in_schema=False`），**功能保留**（产品/worker 仍调用），不删端点；普通创作模式不暴露 G 级/lease/raw JSON/UUID。
- **纵向切片纪律**（设计文档 §10.2）：新 owner 最小可用 → 等价/不变量测试 → canonical 切换 → 当期删除旧写入口/旧投影 → 仅保留有期限兼容 redirect。
- **架构债务守卫**：`test_architecture_debt_manifest.py` 比对 `docs/architecture/legacy-debt-manifest.json`；行号/结构改动后必须用 `python scripts/audit_architecture_debt.py` 重生成清单（否则误报新增 debt）。
- **OpenAPI 快照**：改动蓝图/schema（`include_in_schema`、增删路由）后必须用 `local_drama.main:app.openapi()` 重生成 `docs/openapi/openapi.json`（`test_openapi_release_contract.py` 断言两者相等）。
