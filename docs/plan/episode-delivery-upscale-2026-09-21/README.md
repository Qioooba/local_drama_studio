## 已确定的产品决策

| 决策 | 设计结论 |
|---|---|
| 主入口 | 项目级“整剧交付”，路由 `/projects/:projectId/delivery`，默认进入“分集成片” |
| 单集入口 | 现有单集交付页增加“本集超分 / 前往整剧交付”，定位到同一工作区 |
| 处理粒度 | 一集完整成片一项，不以镜头 Take 或审核收件箱代替整集列表 |
| 默认预设 | 漫剧 1080p、跟随横竖屏、保留原帧率和声音、每张受管 GPU 同时一个超分任务 |
| 首发模型执行 | Real-ESRGAN NCNN/Vulkan 专用适配器；动漫视频、动漫图像风格、通用模型分别提供经验证的配置 |
| 配置归属 | 全局能力与模型管理程序和权重；项目交付设置保存默认方案；工作区允许本批及逐集覆盖 |
| 结果归属 | 原片保留；新增有来源的整集渲染派生版本；人工审核与采用后进入原有交付链 |
| 一键的含义 | 一键应用预设、选择符合条件的分集、统一检查后提交整个批次；真实执行与进度由后台承担 |
| 完整交付范围 | 页面、模型接入、参数、队列、恢复、试跑、审核采用、批量打包、测试、运维说明同时闭环 |

这里的“480p”以文件实测尺寸和时间基为准，不依赖文件名；项目镜头生成规格可以继续保持 480p。超分只改变本次交付派生版本的输出规格。
