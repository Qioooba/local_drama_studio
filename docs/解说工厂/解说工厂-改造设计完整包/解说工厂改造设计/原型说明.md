## 已实现的原型交互

1. 六步唯一数字导航、底部上一步/本步主 CTA；顶部一键生成到预览为次按钮，制作进度可随时打开。
2. 首屏两卡“已有口播稿 / 故事资料”，主题为次入口；资料下分上传/粘贴/链接。已有稿不出现目标时长改稿下拉。
3. TXT/MD 文件真实通过浏览器本地 File API 读取；已有稿上传保留文本，资料上传作为来源。DOCX/PDF/EPUB 仅展示文件选择，不假装完成解析。
4. 稿件可编辑；润色先显示建议，明确采用后更新；示例有 AI 人物/场景识别建议弹窗，明确不运行模型。
5. 人物/场景/道具分类、补充对象、编辑描述、候选预览、采用主参考。上传参考图只演示候选流，不保存或渲染用户图片。
6. 全片风格选择；示例音色/语速和试听动画、单段重读确认，全部注明无真实音频。
7. 分镜左右布局、对应旁白/参考、图片候选本次 1/2/4，追加后保留旧结果，候选点选只预览，明确采用、另行锁定。
8. 图片锁定后不能直接替换；采用新图片将对应视频标为需更新。
9. 静图推拉/AI 动态/已有素材视图；视频候选本次 1/2，可反复追加；重抽视频不改变选定底图；支持预览/采用/锁定。
10. 48 秒示例片段的时间轴定位及播放进度动画；返回对应镜头精修；中文字幕默认开启，额外输出默认关闭。示例仅 480p 可选，720p / 1080p 按能力不可用禁用。
11. 一键生成 6 步进度演示和停止，保留当前选择；示例导出设置可下载 JSON 制作清单，不假装下载 MP4。
12. 使用 localStorage 尽力保留参数/稿件/候选选择及补充资产；若被浏览器禁用，当前页面内仍保持状态。

## 验证范围

- `node --check` 语法检查通过。
- 通过 Node VM 和最小 DOM stub 执行 6 个页面渲染函数，并核对候选追加、预览不采用、采用导致视频需更新、锁定保护、视频重抽不改图、已有稿无时长改写控件。
- 52 个静态按钮 action 标识均有对应处理分支。
- HTML 子页面检查无重复静态 id；所有 6 页渲染产物存在。
- HTML 中未检测到 http 外链、fetch、XMLHttpRequest、WebSocket 或 script src。
- 没有进行浏览器布局测量、实际点击回归、屏幕阅读器测试或真实模型/媒体测试。响应式 CSS 已按桌面、900 px、560 px 编写，实际视觉与交互验收留待授权浏览器环境。

## 原型与实施规格的边界

原型集中演示主路径，没有实现通用资产搜索、真实并发任务、模型动态发现、真实语音历史、视频同步播放器、多语言生成、真实时长重排、后台版本事务等。下拉中的音色、风格与模型名称是示例。正式产品的这些数据必须来自能力目录，不能照抄硬编码。

第 1 步全片动态策略中的 AI 选项因原型没有模型能力而禁用；第 5 步 AI 动态页仍可切换，以展示控件布局，所有生成均明确为示意。

## 最终锁定修正

- 主参考按稳定资产 ID 保存独立锁定状态；已锁定参考不能被采用其他候选替换，追加与一键保留锁定。
- 第 5 步与一键流程遇到“视频已锁定但上游变化”，均停止在第 5 步，不清除失效信息。
- 用户可明确选择保留旧片段，单独记录该决定，并保留旧底图与失效溯源；或选择解锁并重做，追加新视频候选。
- 一键运行期间新发生的锁定冲突也会停止。预览使用已采用视频的底图快照，不跟随上游图片偷换。
- 原型一键的二次点击只用于演示说明，正式产品无需多余确认。
- VM 检查已加入以上关键状态例，52 个按钮动作有对应处理；仍未浏览器实测。

原型聚焦解说工作区内容区，未重复绘制应用全局侧栏；实施时复用现有 AppShell，响应布局按扣除全局侧栏后的容器宽度处理。
