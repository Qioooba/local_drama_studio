## 3. 已知不能在本轮闭环的环境事实

以下项必须按《规范》F6 标 `BLOCKED`/`NOT_RUN`，不得冒充通过：

- 真实 GPU 出图/TTS/I2V：本机无已配置可执行模型时，只能以真实 Job 回执与结构验证证据交付，实拍小样需在用户机器上补做。
- 浏览器截图：以真实启动的 API + Vite 页面与前端测试替代；无受支持浏览器时标 `BLOCKED`。
