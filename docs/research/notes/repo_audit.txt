13. 完成定义
========================================================================

稳定性：
- 所有 V2 route 在真实空项目和大项目都不进入默认 Error Boundary。
- API non-Comfy、Vitest、typecheck、lint/mypy 全绿。
- 无 stale release evidence。
- P12 READY 必须来自真实 UAT，不是假 JSON。

正确性：
- 从任意 Director shot 到 Generation，shot_id 全链一致。
- 一个 capability 在设置页、Director、manual generation、Episode Run、worker 得到同一 resolution。
- 每个 Job/Variant 可追溯 input/model/workflow/seed/media/identity pack。
- 上游变更能标记下游 stale。
- selected/adopted/approved 各自独立。

体验：
- Story、Plan、Director、Generation、Review、Audio、Timeline、Run 各只有一个清晰主目标。
- 主要操作首屏可见；高级设置不默认铺满。
- 对话框、抽屉、tabs 完整键盘可用。
- 大列表可搜索、分页或虚拟化。
- 失败都给下一步 deep link。
- 用户可以知道 worker 是否真的运行，而不是只知道 API 在线。

可靠性：
- 浏览器关闭不影响已由活跃 worker 接管的任务。
- worker crash 可回收 lease。
- DB/文件 crash 可 reconcile。
- 迁移前备份、迁移后校验。
- 长文/大媒体不会因 read_bytes 造成不可控内存峰值。

安全：
- 默认 LOCAL_ONLY 和 loopback fail closed 不退化。
- 云供应商只有在 Connected Edition 明确启用。
- secret 永不进入 Profile JSON、SQLite 明文、日志和导出包。
- 所有外发有 consent、审计、预算和取消。
