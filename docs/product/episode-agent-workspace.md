# 本集 Agent 工作台重构方案

## 决策

把“分集策划”和“整集生产”合并成一个创作者入口：**本集制作**。

普通用户不再逐项配置角色、场景、镜头类型、首尾帧、模型、分辨率和每镜生产状态。系统从已经确认的故事与项目设置中继承这些约束，由 Agent 分阶段推进；只有遇到歧义、质量问题或人工检查点时才请求处理。

## 用户看到的五个阶段

1. **方案与设定**：本集故事、角色/场景增量和镜头方案。
2. **关键画面**：关键帧、必要的首尾帧和连续性基准。
3. **动态视频**：逐镜视频候选与工作版本。
4. **声音字幕**：人声、字幕和对白同步。
5. **合成质检**：时间线、整集渲染与机器质检。

这些阶段是对现有生产事实的聚合视图，不新增第二套状态或任务系统。

## 唯一的启动决策

创作者只需决定：

- 质量：预览 / 标准 / 精品。
- 确认方式：仅异常时暂停（默认）/ 批量生成视频前确认。
- 是否生成人声。

分辨率、画幅、帧率和模型沿用项目设置；需要变更时进入项目设置，而不是在每集重复填写。

## 渐进披露

- 默认展示阶段进度、当前运行和真正需要处理的异常。
- 异常卡只显示问题、影响和一个修复入口。
- 全部镜头事实、技术参数和原文证据不占据主页面；分别归入镜头修正、项目设置和故事工作区。
- `/episodes/:episodeId/production` 仅作为旧链接兼容地址，跳转到 `/plan`；导航只保留“本集制作”。

## 删除边界

从普通分集页面删除：镜头表/故事板/时间线三视图切换、场景手工分组、原文证据标签页、Beat 重排抽屉、独立的整集生产入口、逐镜五阶段常驻列表。

镜头工作台仍是异常修复和高级导演编辑器；后期、交付、系统任务和项目设置保持各自的数据所有权。

## 真实性约束

- Agent 不伪造人工批准，不把“已选中”显示为“已批准”。
- 启动前仍执行真实预检；失败不创建生产任务。
- 自动模式只在既有工作流允许的范围内继续，命中人工门或异常即暂停。
- 页面只投影现有 Episode Production 事实，不建立并行状态机。

## 上游与按集生成合同

上游只负责建立可追溯的分集边界，不再一次生成全剧所有场次和镜头。每集至少保留：`episode_id/code/title`、摘要或 logline、`source_document_version_id` / `import_session_id`、原文段落起止、`target_duration_ms`，以及项目级核心资产和视觉记忆。

“开始本集”使用现有按集拆解能力：以 `episode_id + source_paragraph_start/end` 请求 AI 分场与镜头草稿。草稿质量为 READY 时由编排层自动应用并保留版本历史；只有 REVIEW_REQUIRED、BLOCKED 或核心资产身份冲突才暂停。EpisodeFrontHalfActionService 继续作为事实校验器，不冒充生成器。
