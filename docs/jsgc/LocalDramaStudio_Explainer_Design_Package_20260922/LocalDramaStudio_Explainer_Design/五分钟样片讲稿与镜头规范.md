# 虚构故事工程验收样片｜灯塔最后一页值班记录

> 本文是可供开发与验收使用的原创样片规格。人物、地名、1936 年背景与事件均为虚构。**当前未生成图片、配音或视频，也未测试任何模型效果。** 文中全部片上时码、秒数、帧号均为 **planned（计划值）**；实际生成必须先完成 TTS 与对齐，再重排时间轴。

## 1. 验收范围与输入边界

这部样片验证一个完整、可解释、可重复的五分钟解说生产闭环：原创输入 → 实体与事实包 → 叙事与镜头 → 参考资产 → 本地配音 → 字幕对齐 → 混合画面生成 → 合成 → 中英版本 → 检查与交付。它**不验证真实历史事件的搜索、来源可信度或史实真实性**。事实包里的 `verified_as_history: false` 必须原样传递，不能为了通过流程而改成已核验史实。

真实历史检索另用独立用例：输入一个可核验的真实事件，要求原始来源 URL、发布日期/访问时间、逐条主张与证据对应、时间线冲突、人物同名消歧、来源撤回与不确定事实阻断。只有真实资料用例通过，才能声称系统的历史检索能力通过；这部虚构样片不能替代。

原始故事悬疑来自“只见局部信息”，不是隐藏反派。结局只有一个：灯室光源从未熄灭；预定检查让内部观察窗无光 47 秒；日志末页按安排夹在灯室门边，只因背面向外未被认出。最后不能追加第四个人、鬼怪、有人毁证或阴谋彩蛋。

### 1.1 三种内容身份

| 内容 | 本样片如何标记 | 可否当成真实史实 |
|---|---|---|
| 正文事件主张 | `authored_fiction_fact_pack`，引用 F001–F018 | 不可；只可核对内部一致性 |
| 原创表达 | 开头的疑问、结尾的提问、悬念安排 | 不可；不能把问句自动转换成肯定事件 |

这是叙事工程用的虚构灯塔装置，不是现实灯塔操作、维修或航海安全教程。可读记录、时间和姓名必须由排版层绘制，不能让图像模型凭空写字。

### 3.2 两个场景与两个核心道具

- **LOC_LANTERN / 灯室**：楼上圆形灯室，铜色固定灯具始终亮；灰蓝墙面；门内右侧有固定纸夹；观察构件为虚构场景装置。布局锁：灯具位于场景中心偏左；固定纸夹在门内右侧；门边在干燥室内；禁止把光源直接熄灭。
- **LOC_WATCH / 值班室**：楼下室内，木质桌面；一侧为看见户外风雨的外窗，另一侧为通向灯室光源的内部观察窗；两窗用途必须区分。布局锁：外窗只能显示风雨，不承担灯光是否熄灭的证据；内部观察窗固定在桌后墙面；日志主要在桌面中间。
- **PROP_LOG / 值班日志**：深棕封面、米灰纸页，末页属于该日志；可拆夹式记录册，取下页不是撕毁；仅一册与一张末页。一致性：21:10 到21:30末页在灯室门边或被取下检查；21:30后回册；原始原因待核记录保留。
- **PROP_BELL / 铜铃**：小型铜色手持铃，深棕短柄；只有一个。一致性：21:16 在沈砚手中；21:32 在值班室合上日志旁；不得无故复制。

“两个道具”指需独立身份和状态追踪的核心可移动道具。窗、桌、灯具、纸夹等固定布景不因此消失；它们归场景资产管理，不能在不同镜头随意改变位置。日志用可拆夹式设定，以免取页画面误导为撕毁记录。

### 3.3 固定视觉风格

统一采用灰蓝铜色叙事插画：深灰蓝 `#263C4D`、石板蓝 `#667D8D`、铜色 `#B78254`、米灰纸色 `#E4DDD0`。稳定线条、轻纸感和克制暖光贯穿全片。人物是插画身份，不模仿真实历史人物。禁止混入写实摄影脸、随机年代服装、血腥、假档案印章、新闻台标或泛黄“史料”水印。

全片保留“原创虚构 · AI画面演绎”角标；第一帧至开头 5 秒应显著出现“虚构故事工程验收样片”；片尾再次说明。角标、字幕和信息卡使用精确字体与合成图层。

## 4. 300 秒 planned 时间预算

完整中文旁白共 **1117 个汉字**（含标点共 1252 字符），英文译稿按空白分词计 **696 个词项**。这是文本统计，不是实际语速或 TTS 时长测量。24 段旁白映射 40 个镜头，25 fps，planned 总长 300 秒 = 7500 帧。镜头与段落区间均为 `[start, end)`；第一个镜头从第 0 帧开始，最后一个镜头的排他终点是第 7500 帧。

计划采用 **20 个静帧动效镜头 + 12 个 I2V 镜头 + 8 个精确排版信息卡/场景细节镜头**。分类是计划目标，不是已经完成的资产数量。模型不支持指定长度时，按能力声明生成可用时长后选取合格片段；支持首尾帧才传双端条件。I2V 失败应允许降级到审核过的首帧动效，并在实际报告里记录“计划类型”和“实际类型”，不能把降级后的镜头算作 I2V 成功。

5 秒开场钩子是计划值。英文第一段若无法自然放入 5 秒，需要压缩同义表达或微调片头安排，不得直接截掉单词。中英每个配音版独立 TTS、独立对齐、独立重排；同一中文音轨上的中英字幕可以共享实际语音语义分段，英文配音版则不能照搬中文实际时码。

### 6.1 首尾帧与运动策略

静帧动效用一张通过审查的高分辨率母图和确定性轻推、平移、分层视差即可；不用为每个镜头额外生成两张很相似的脸。信息卡由矢量和字体排版绘制，背景可以用同一场景插画。需要精确纸页文字翻转时，采用二维/三维合成，不将字符一致性押在生成视频上。

I2V 的首帧引用已审核实体包、场景包和构图；第二帧在 JSON 中表示可选的末端目标，不代表任何本地模型必然支持首尾控制。适配器若声明 `supports_end_frame=false`，不得发送末帧参数。可使用首帧生成、审核末端帧，再选择切出点；质量仍不足就降级为同一母图动效。对话口型不是本片需求，不增加口型模型、三套角色声音或多说话人对齐链路。

铃声三次、观察窗局部亮度变化、纸页翻面和所有可读字符均有确定性备选。最多两次针对性生成修复之后仍失败，默认走备选并进入异常队列；不能无限抽卡。本片固定母图复用用于身份稳定，不能用同一面部特写机械重复填满全片。长静帧镜头应依靠构图与信息变化服务叙事，实看片疲劳时优先重新分镜。

## 7. 配音、字幕、音乐和多语言验收

### 7.1 配音与实际时间轴

使用一位中性成年叙述者，语速平稳、咬字清楚、悬疑克制。三个人物没有独立对白或口型表演。中文姓名与英文转写固定为沈砚 / Shen Yan、林澄 / Lin Cheng、周禾 / Zhou He、岚湾灯塔 / Lanwan Lighthouse。中文的“九点十七分”与信息卡的 `21:17:00` 对应，口语和数字形式需要规范化后比较。

正确顺序是：批准旁白 → TTS → 实测时长与强制对齐 → 语义停顿与镜头重排 → 生成实际字幕 → 渲染。planned 时码不能直接写成最终 SRT。轻微时间伸缩的验收预设范围为 0.97–1.03，仍须听审。较长语句优先重排视觉；只有未人工锁定、且政策已授权的文字可创建新修订并重新核对译稿。此验收样例默认锁定文字；无法自然容纳时应报告时间预算问题，不能自动改写。最后使用经过设计的片头片尾和无语音留白补齐目标 7500 帧，不能靠截断音频凑 300 秒。

### 7.2 字幕

中文单行目标不超过 18 汉字，最多两行；英文单行目标不超过 42 字符，最多两行；单条目标展示 1.2–6.0 秒。以上为可配置的本项目排版预设，不是平台强制规则。双语模式采用中文一行与英文最多两行，超长先按语义切分，避免四行遮住画面。横版与竖版分别验收遮挡、安全区和可读性。

英文配音版的信息卡、角色名和虚构披露也要本地化，不能只翻译对白字幕。JSON 提供中英画面词典，例如“交接检查 / Handover Inspection”“原因待核 / Cause Unconfirmed”“原创虚构 · AI画面演绎 / Original Fiction · AI Visualization”。24 小时时间码可以保持相同数字，但两种语言对其解释必须一致。

姓名、47 秒、21:17:00、21:17:47、否定词“未/没有/not”必须硬性复核；字幕不能在镜头回溯后仍让上一时段的内容产生误导。与主规范一致，标注验收集字幕边界误差 P95 目标不超过 150 ms；本样片关键字幕单项边界误差上限为 200 ms，两项分别验收。用 ASR 做差异提示，再对原始脚本、实际音频和成片三方比对，不能把 ASR 转写视为绝对真值。

### 7.3 音乐、音效与听审

- 00:00–00:42（planned）：低密度悬疑音色，开头不给惊吓音效。
- 00:42–02:50（planned）：轻脉冲递进；叙述始终在前景。
- 02:50–04:21（planned）：线索对齐后逐步变暖；计划/结果信息卡降低音乐存在感。
- 04:21–05:00（planned）：和声缓解，最后2秒自然收尾。

铜铃在故事 21:16 对应三次明确音效；画面手部动作失败时固定画面配准确铃声。回溯若重复同一铃声，需要时间提示，不能听成又敲了三下。雨声只承担环境关系，不压过姓名和关键数字。避免“心跳、惊吓、反派出场”等会额外暗示阴谋的音效。

初始混音验收预设为综合响度约 -16 LUFS、容差 ±1 LU，真峰值 ≤ -1 dBTP，讲话时 BGM 约低于人声 14–20 dB，均需按素材和实际听感调整。这些数值是项目建议配置，不宣称任何平台的统一标准。最终要完整听完中英文各自成片，而不是只抽查配音片段。

## 8. 逐帧、内容、字幕与音频审查

### 8.1 自动审查与人工审查分工

全部帧运行技术扫描，寻找黑帧、解码错误、异常亮度跳变、缺帧、重复坏帧、意外闪烁与画面尺寸变化。40 个镜头至少各出首帧、中帧、末帧，以及每次转场接缝图。多模态模型检查人物身份、光源是否错误熄灭、末页是否多出、文本与旁白是否矛盾。命中异常后展开连续帧，记录具体帧区间；自动检查得分不等于已完成人工逐帧内容审查。

本样片属于开发验收，至少一次完整人工看片、一次完整人工听审与字幕核对应真实完成并记录审查人/时间/问题。日常无人值守运行可依策略自动批准低风险镜头并集中处理异常，但不能把“尚未人工看过”报告成“已人工审查”。所有严重问题阻断发布包，仅允许输出带失败说明的诊断包。
