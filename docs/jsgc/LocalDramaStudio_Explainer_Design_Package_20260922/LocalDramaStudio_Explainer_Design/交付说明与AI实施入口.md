## 这次交付了什么

这是一套完整版本的产品、开发和验收规范。目标是在现有系统中增加独立“解说工厂”，从选题/来源/讲稿到本地生成、多语合成、审片与多平台交付。本包没有修改产品仓库，没有连接用户本地GPU，没有生成真实图片、语音或MP4；这些必须由后续实施按验收要求完成。完整规格与实际实现、实际成片是不同交付状态。

## 给实施AI的执行指令

请先完整读取主规范、源码接入清单、测试矩阵与样片合同，再审查开发时最新仓库。将当前HEAD与上述基线做差异比对；保留新变化，更新设计接入点，不能按旧行号直接覆盖代码。

在同一个完整版本中实现全部核心能力。W01—W12是工作包和依赖顺序，可以并行；不得用“以后再做多语言、长片、恢复、审片”缩小完成范围。每条需求关联实现文件、测试ID和实际证据，所有未执行项如实保持NOT_RUN/BLOCKED。不要在没有运行模型的情况下承诺速度、人物一致性或成片质量。

正常路径应允许用户从“解说工厂”点击“检查并一键生成”，随后由后台持久工作流继续。机器检查通过的内容可自动导出；关键异常集中呈现，只修受影响部分。研发验收要求完整看片、听审及注入缺陷验证，不意味着日常每条片都必须逐镜人工批准。

### 不能偏离的设计决定

1. 新项目类型`EXPLAINER`、独立Video/Edition/Composition；不创建虚假Episode。
2. 新增六个解说工作页，复用AppShell、控件、模型中心、媒体和任务设施；旧短剧语义保留兼容。
3. 既有automation workflow/Job/Attempt是执行状态真源，解说run/binding只是业务范围、快照和投影。
4. 初次预检冻结输入、策略、能力、预算和任务骨架；内部合法展开研究/TTS子计划不让自己过期，外部编辑才触发相关失效。
5. 默认AUTO_WITH_EXCEPTIONS；机器政策接受、真实人工批准和发布授权分开记录。
6. 旁白由真实TTS/对齐决定时钟；英文配音版独立编排，不能套中文绝对时码。
7. 人工锁定讲稿和镜头不得被自动修复覆盖；所有变化新增版本并传播失效。
8. 推理LOCAL_ONLY与允许网页研究是独立策略；所有推理HTTP出站在最终传输层受控，不能暗中转云。
9. 同一调度时点只执行一次，唯一键仅为schedule_id + scheduled_for；config_revision仅为快照。
10. 全帧技术解码、视觉语义抽样、指定区间深度逐帧、人工实际审阅分别报告覆盖；不把抽样写成全片理解。
11. 全球分发需要模型、LoRA、音乐、字体、声音参考和素材的实际用途许可。当前H3路径须依官方许可核实；不能靠换导出名洗掉限制。
12. 完整实现至少交付真实5分钟样片与30分钟连贯长片、恢复证据、多语/多画幅包、旧短剧回归和90项测试结果。失败报告可以解释阻塞，但不能代替完整通过。

## JSON合同的适用边界

run-intent表示用户希望生产什么。`fixture:`来源与栏目引用仅在本设计样例中存在；实现应先导入真实文档、创建真实栏目revision，再由服务端预检解析引用、核对同项目权限/锁定、检查能力/许可/预算，生成plan_hash并提交既有工作流。不能把示例直接发到当前产品接口，也不能把JSON schema校验通过当作模型就绪或具备发布授权。

示例中的10小时GPU预算和12小时墙钟预算是可配置停止上限，不是预计耗时。实际时长必须由本机profile测量。请求GLOBAL导出不意味着所选资产已取得全球许可；预检仍须判定。示例请求EXPORT_ONLY，不触发外部发布。

JSON schema负责形状与局部不变量；实施还须在领域层验证edition_key唯一、语言映射、时间有理数、来源/栏目版本、预算相互约束、schema以外的真实能力和用途限制，并补入相应测试。完整RenderManifest、QC报告和各operation输出schema须依据主规范在实现中形成Pydantic/OpenAPI合同与生成客户端。

## 如何复核本资料包

在解压目录运行：

```bash
python -m pip install jsonschema
python validate_design_package.py
```

脚本实际检查Draft2020-12合同、8个非法输入、样片计数与引用、中文计划帧区间、英文独立时钟、测试矩阵状态和原型网络引用。它不会调用本地模型、启动原产品、上传作品或证明成片成功。重新运行会更新静态检查报告时间与内容；如需保留原始记录，请先复制目录。

对本包的真实检查包括：24段和40镜头均连续覆盖中文计划[0,7500)帧；3人物、2地点、2道具、18事实及52关键帧/构图锚点引用完整；镜头类型20/12/8；中文1117汉字、含标点1252字符，英文按空白计696词项。最终音画字幕的质量与真实时长仍等待产品实现及实机验收。

## 审查冲突时采用哪份文件

主规范定义产品范围和核心架构；源码清单解释具体接入；测试矩阵定义如何证明完成；样片规范定义一个具体的可重现内容输入。原型是界面交互示意，不能覆盖领域合同。主规范的默认自然时长±5%与灯塔fixture明确选择的中文精确300秒属于两个受支持模式，不构成冲突。

发现冲突时先修正文档和合同再改代码，记录改动原因与影响；不得为使测试显示绿色而偷偷减少验收范围、降低事实要求或把实际未运行的模型步骤改成mock成功。
